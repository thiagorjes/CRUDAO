# SPDD Integration — CRUDAO
_Versão: 1.0 | Data: 2026-08-22_

## Canvas

O sistema CRUDAO usa o REASONS Canvas (`docs/spdd/[feature]-canvas.md`) como fonte de rastreabilidade por feature, atualizado progressivamente pelas skills do pipeline (`/discovery`, `/prd`, `/techspec`, `/tasks`, `/code-review`).

## Estado do projeto

`memory/state.md` é a fonte de verdade do estado operacional (features ativas, artifact registry). `memory/constitution.md` concentra ADRs e princípios estáveis.

## Fluxo de trabalho do time

- Uso individual/pequena equipe nesta fase — sem múltiplos aprovadores formais definidos.
- Aprovação de PRD/TechSpec: usuário único (Product Owner/Tech Lead do sistema).
