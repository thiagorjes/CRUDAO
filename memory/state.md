Solução adotada: **ticket de curta duração** — `POST /api/ws-ticket` (backend, autenticado via Bearer normal) emite um ticket opaco de uso único e TTL de 20s; o Next.js repassa ao browser só esse ticket (proxy `/api/ws-ticket`), que o usa como `?ticket=` no handshake SockJS; o access token real nunca sai do servidor. Decisão: qualquer evento recebido (e toda (re)conexão) dispara `router.refresh()` (Server Component do board refaz `GET /board` com Bearer), o que automaticamente cobre tanto "atualização em tempo real" quanto "gap de seq"/"reconexão dispara resync" sem precisar de lógica de merge incremental no cliente.
